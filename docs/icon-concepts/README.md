# Icon concepts

Unselected app-icon studies for Silvercam / 銀鹽工坊. These files are reference only. They are not wired into the Android app, the website, or the launcher, and none of them replaces the shipping mark.

Reviewed as design archives, not as a chosen direction:

- `01`–`10` are original 512px SVG studies (safelight, silver-halide crystal, grease-pencil contact sheet, film-advance lever, cinnabar seal, dichroic enlarger dial, halation, DX canister, Bayer-to-grain, Bauhaus aperture). The SVGs contain no scripts or external links.
- `gpt-image/` and `grok-image/` are raster explorations. Several include generated lettering or marks that are not a cleared wordmark. Do not ship a raster from this folder as the icon without redrawing it.

`.DS_Store` files from the source checkout were left out.
