2026-11-10 — Initial Kotlin/GLSL Port & Binary Data Baking
  - Baked upstream JSON film/paper profiles (src/spektrafilm/data/profiles/*.json)
    and optical databases from spektrafilm v0.3.4 (commit 3bb2c2d) using
    tools/bake/bake_spektrafilm.py into compact SPK1 binary files (*.spk) for
    mobile runtime loading:
      * film/*.spk (20 film stock files including Portra 800 Push 1 & Push 2)
        containing density curves, sublayer curves, dye absorption spectra,
        base density, Hanatos 2025 spectral-upsampling LUTs (tc_lut, fp16),
        CAT16 sRGB-to-XYZ matrices, and direct-scan 3D LUTs (scan_lut, fp16).
      * paper/*.spk (8 print paper/film stock files) containing spectral
        sensitivities, fitted model density curves, dye absorption spectra,
        base density, and scanner 3D LUTs (scan_lut, fp16).
      * global.spk containing 380–780 nm (5 nm) wavelengths, TH-KG3 enlarger
        illuminant, custom dichroic C/M/Y filter transmittances, and the
        neutral print filtration database.
      * index.json indexing the baked film and paper stock metadata.
  - Note: Individual binary .spk files were not re-encoded with per-file text
    headers; attribution and license terms accompany the collection via
    SPEKTRAFILM_LICENSE.txt, this CHANGELOG.txt, and the application's About /
    Open-Source Licenses screen.

2026-11-11 — Attribution, Licensing Notices & Independent Display Branding
