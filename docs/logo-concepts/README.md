# Logo concepts

Unselected logo studies for Silvercam / 銀鹽工坊. These files are reference only. They are not applied to the app icon, website header, or any other shipping surface.

Reviewed as design archives, not as a chosen direction:

- `gpt-logo/` — wide lockups and monograms, including film-strip S marks and wordmarks.
- `grok-logo/` — square studies (crystal lattice, wax circle, darkroom vernier, silver arc, seal / film gate).
- `minimax-image/` — flat geometric studies. Some frames contain garbled generated letters (for example a broken 銀). Treat them as composition references, not as finished type.
- `nano-banana/` — geometric darkroom marks (enlarger slit, sprocket seal, spool monogram, halation, wax crop, silver-halide crystal).

Do not trace a generated raster into the product without a clean redraw. No concept in this folder was selected.
